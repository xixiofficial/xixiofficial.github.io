hellosystem，一个看起来像macOS的系统

发表于2024-10-02|更新于2024-10-21|FreeBSD

前言

这里只是简单体验hellosystem

一、总述

helloSystem 是一个开源的桌面操作系统，以优雅的 macOS 风格界面、用户友好设计和注重隐私为核心理念。
它基于 FreeBSD，专为创意工作者和追求简洁体验的用户打造，被称为”面向人文的操作系统”。本文全面解析其历史渊源、发展脉络，并提供详细的 VMware 安装教程。

二、由来：从理念到现实

1. 诞生背景 (2020)

  • 创始人：德国开发者 Simon Peter（曾主导 AppImage 项目）
  • 核心动机：
    • 回应现代操作系统日益复杂化的趋势
    • 创建”无追踪、无广告、无用户对抗”的纯净系统
    • 为创意工作者提供类 macOS 的直观体验
  • 命名哲学：”hello” 象征友好、开放和易用性

2. 技术根基

层级 技术组件 特点
底层 FreeBSD 13+ 提供企业级稳定性与安全性
桌面环境 定制化 Qt/KDE 框架 深度优化的 macOS 风格 UI
核心创新 Filer 文件管理器 空间浏览模式 (模仿 Finder)
Dock 任务栏 可视化应用启动器
Control Center 控制中心 一体化系统设置

三、发展历程：从实验到成熟

1. 里程碑版本演进

  • **v0.1 (2020-12)**：概念验证版，基础桌面环境搭建
  • **v0.3 (2021-03)**：引入革命性 Filer 文件管理器
  • **v0.5 (2021-10)**：支持 AppImage 应用格式，生态突破
  • **v0.7 (2022-08)**：实现系统更新功能，增强稳定性
  • **v0.8 (2023-04)**：正式支持 VMware/VirtualBox 虚拟化
  • **最新版 v0.9 (2024-01)**：硬件兼容性提升，支持更多 Wi-Fi 设备

2. 核心设计哲学

四、VMware Workstation 安装指南

1. 准备工作

  • 所需文件：
    • helloSystem 镜像：官网下载 .iso 文件 (最新版 0.9.0)
    • VMware Workstation 17 Pro (或 Player)
  • 推荐配置：
    • CPU：2核+ (启用虚拟化 VT-x/AMD-V)
    • 内存：4GB+
    • 磁盘：40GB+ 动态分配
    • 网络：NAT 模式

问题现象 解决方案
启动黑屏 编辑.vmx文件添加：svga.vramSize="268435456"
鼠标漂移 安装后立即升级 open-vm-tools
Wi-Fi 不可用 选择 Intel 或 VirtIO 网卡
分辨率异常 终端执行：sudo vmware-config-tools.pl

五、总结与展望

1. 系统定位优势

  • 美学体验：极简主义设计媲美 macOS
  • 隐私保护：无遥测/无广告/无用户追踪
  • 创新交互：空间文件管理+全局菜单
  • 轻量化：基础安装仅占用 2.5GB 磁盘

3. 未来发展方向

  • 硬件兼容：完善 NVIDIA/AMD GPU 支持
  • 应用生态：深化 Flatpak/AppImage 整合
  • 云集成：开发 helloCloud 同步服务
  • 移动端：探索平板设备适配
