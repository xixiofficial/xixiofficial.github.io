一、Maven 是什么？（通俗易懂讲解）

核心定义

Maven 是 Java 项目的构建与依赖管理工具，简单说：帮你管理 jar 包、编译代码、打包项目、运行测试，告别手动导包、手动配置的麻烦。

核心作用

依赖管理：自动下载 jar 包及其关联包，无需手动找包、导包
项目构建：一键完成编译→测试→打包→部署
统一规范：所有项目目录结构、配置格式一致，团队协作更高效
跨平台：Windows、Mac、Linux 通用

二、Windows 系统搭建 Maven（详细步骤）

前置条件
必须先安装 JDK 8+ 并配置好 JAVA_HOME 环境变量（未配置先装 JDK）。

步骤 1：下载 Maven

打开官网：https://maven.apache.org/download.cgi
找到 Binary zip archive，下载最新版（如 apache-maven-3.9.9-bin.zip）
解压到无中文、无空格路径（推荐）：
D:\Environment\apache-maven-3.9.9

步骤 2：配置系统环境变量

右键「此电脑」→「属性」→「高级系统设置」→「环境变量」
新建系统变量：
变量名：MAVEN_HOME
变量值：D:\Environment\apache-maven-3.9.9（你的解压路径）
编辑 Path 变量：
新建 → 输入 %MAVEN_HOME%\bin → 一路确定保存

三、IDEA 配置 Maven（全局生效，一劳永逸）

步骤 1：打开 IDEA 全局设置

打开 IDEA → 顶部菜单栏 File → Settings（快捷键 Ctrl+Alt+S）
左侧找到：Build, Execution, Deployment → Build Tools → Maven

步骤 2：核心配置（关键！）

Maven home path：选择本地 Maven 根目录
例：D:\Environment\apache-maven-3.9.9
User settings file：勾选 Override，选择 conf/settings.xml
Local repository：自动读取本地仓库路径，无需修改

四、IDEA 中使用 Maven 快速测试

右侧边栏点击 Maven 图标，打开 Maven 面板
常用命令（双击执行）：
clean：清理项目编译文件
compile：编译代码
test：运行测试
package：打包项目（生成 jar/war 包）
无报错、依赖正常下载 → 配置完成！

五、常见问题解决

mvn 不是内部命令：环境变量配置错误，检查 Path 和 MAVEN_HOME
依赖下载失败：确认阿里云镜像配置正确，重启 IDEA
IDEA 不识别 Maven：重新选择 settings.xml，刷新 Maven 依赖
