一、lxml 概述

1.1 什么是 lxml

lxml 是 Python 中一个高效、功能丰富的 XML 和 HTML 处理库，结合了：

  • libxml2 的高性能
  • ElementTree 的简单 API
  • 强大的 XPath 和 XSLT 支持

1.2 核心特性

  • 支持 XML 和 HTML 解析
  • 完整的 XPath 1.0 实现
  • XSLT 1.0 转换支持
  • 基于 ElementTree 的 API
  • 高性能解析（比内置 xml 模块快 10-100 倍）
  • 优雅的错误恢复机制
