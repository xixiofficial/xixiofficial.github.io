Cloudfare 的进阶使用

发表于2025-11-15|更新于2025-11-27|Cloudfare
|浏览量:

一、前置准备

必备工具与账号
注册并登录 Cloudflare 账号（免费版即可）
拥有一个已备案的域名（国内服务器需备案，境外服务器可免备案）
本地设备安装 Clash 客户端（Windows/Mac）或 Clash Premium（Linux）
可选：服务器一台（如 VPS，用于中转节点，推荐境外节点提升稳定性）
环境要求
服务器系统：CentOS 7+/Ubuntu 18.04+（若使用中转）
本地网络：能正常访问 Cloudflare 官网（需提前解决网络连通性）
域名解析：确保域名已指向 Cloudflare（后续步骤会详细说明）

二、Cloudflare 核心配置（关键步骤）

1. 域名添加与解析设置

登录 Cloudflare 后台，点击左侧「Websites」→「Add a site」，输入你的域名（如example.com），点击「Add site」。
选择免费套餐（Free Plan），点击「Continue」。
Cloudflare 会自动扫描现有 DNS 记录，删除无用记录后，添加一条 A 记录：
Type：A
Name：自定义子域名（如clash，最终访问地址为clash.example.com）
Content：填写服务器 IP（若无需中转，可填写 Cloudflare 节点 IP，需提前查询可用节点）
Proxy status：开启（橙色云朵图标，启用 Cloudflare 代理）
点击「Continue」，按照提示修改域名的 Nameserver 为 Cloudflare 提供的服务器（如ivan.ns.cloudflare.com和lisa.ns.cloudflare.com），修改后等待 DNS 生效（通常 10-30 分钟）。

2. Cloudflare Workers 配置（实现节点中转）

点击左侧「Workers & Pages」→「Create application」→「Create Worker」。
输入 Worker 名称（如clash-proxy），点击「Deploy」，部署成功后点击「Edit code」。

3. SSL 证书配置（确保 HTTPS 加密）

回到 Cloudflare 域名管理页面，点击左侧「SSL/TLS」→「Overview」。
选择「Full」模式（推荐，需服务器支持 SSL，若无需服务器可选择「Flexible」）。
点击「Edge Certificates」，开启「Always Use HTTPS」和「HTTP Strict Transport Security (HSTS)」，增强安全性。

2. 导入 Clash 并启动代理

打开 Clash 客户端，点击左侧「配置」→「导入配置文件」→「选择本地文件」，选中刚才创建的config.yaml。
导入成功后，点击左侧「代理」，在「Proxy」分组中选择「Cloudflare-Worker」。
点击客户端顶部「打开系统代理」，此时本地设备已通过 Cloudflare 代理访问网络。

四、测试与故障排查

连通性测试

  打开浏览器，访问 IP 查询网站，若显示的 IP 为 Cloudflare 节点 IP 或服务器 IP，说明代理成功。
  尝试访问境外网站（如 Google、YouTube），若能正常加载则配置有效。

常见问题解决

无法访问境外网站：

  检查 Cloudflare Worker 脚本中的targetUrl是否正确（需为可用节点）。
  确认 Clash 配置文件中的server和port与 Worker 地址一致。
  检查 DNS 是否生效（可通过nslookup clash.example.com查询解析地址）。

SSL 证书错误：

  确保 Cloudflare SSL 模式为「Full」或「Flexible」。
  关闭 Clash 中的skip-cert-verify（避免安全风险）。

速度较慢：

  更换 Cloudflare 节点（可通过Cloudflare 节点查询工具选择低延迟节点）。
  优化 Worker 脚本，减少转发层级。

五、注意事项

遵守当地网络法规，仅用于合法用途（如学习、工作访问境外资源）。
Cloudflare 免费版有流量限制（每日约 10GB），若需大流量可升级付费版。
定期更换节点地址和 Worker 脚本，避免被屏蔽。
不要分享自己的 Clash 配置文件和 Worker 地址，防止滥用导致账号被封。
