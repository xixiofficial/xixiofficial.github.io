OpenClaw

发表于2026-04-05|更新于2026-04-05|Tools
|浏览量:

总述

OpenClaw（小龙虾） 是本地可部署的 AI 助手框架，支持对接大模型、接入飞书 / 企业微信等渠道。
macOS 13 上核心要点：

  • 必须 Node.js 22+
  • 用 官方一键脚本 安装
  • 飞书用 WebSocket 长连接（最稳、不用公网 /ngrok）
  • 飞书配置：AppID + AppSecret + 权限 + 事件订阅

macOS 13 环境准备（必须）

打开终端

聚焦搜索（Command + 空格）→ 输入 Terminal

安装 Homebrew（没装就执行）

安装 Node.js 22（推荐 brew）

验证：

要求：v22.x 以上。

解决 macOS 13 权限（常见坑）

  • 系统设置 → 隐私与安全性 → 完全磁盘访问权限
  • 勾选：终端 /iTerm
  • 修复 brew 权限（M1/M2）：

–

安装 OpenClaw（macOS 13 官方方式）

一键安装（推荐）

它会自动：

  • 装CLI
  • 装 daemon（后台服务）
  • 配置环境变量

验证安装

输出版本即成功。

启动服务（本地网关）

默认端口：18789

浏览器访问：

看到 OpenClaw 控制台即正常。

三、飞书开放平台创建应用（关键）

进入飞书开放平台

https://open.feishu.cn/
登录 → 开发者后台 → 创建企业自建应用。

填写应用信息

  • 应用名称：OpenClaw助手
  • 图标、描述随便填
  • 创建

添加「机器人」能力

左侧：添加应用能力 → 机器人。

拿到 AppID / AppSecret

左侧：凭证与基础信息
复制并保存：

  • App ID（cli_xxxx…）
  • App Secret（很长一串）

开通权限（必须）

左侧：权限管理
开启以下（搜索 im: 即可批量勾选）：

  • im:message:readonly
  • im:message.p2p_msg:readonly
  • im:message:send_as_bot
  • im:resource
  • contact:user.base:readonly

事件订阅（长连接，不用公网）

左侧：事件与回调 → 事件配置
请求方式：使用长连接接收事件（WebSocket）
添加事件：搜索并勾选 im.message.receive_v1（接收消息）
保存

发布应用

左侧：版本管理与发布 → 创建版本 → 发布
个人应用一般自动审核通过。

OpenClaw 安装飞书插件并配置

安装飞书插件

自动安装并重启服务。

进入飞书配置向导

依次输入：

  • App ID（从飞书复制）
  • App Secret（从飞书复制）
  • 选择连接模式：websocket（推荐）
  • 站点：China
  • 群聊策略：open（@机器人即可回复）
  • 系统：macos

重启 OpenClaw 生效

测试飞书聊天

飞书 → 通讯录 → 找到你的应用 → 发起私聊
发一句：你好
OpenClaw 控制台看到日志、飞书收到回复 → 成功。

macOS 13 常见坑 & 解决

command not found: openclaw

端口 18789 被占用

飞书收不到消息

确认事件订阅是长连接
权限全开、AppID/Secret 正确
重启 openclaw + 重启飞书应用

总结

macOS 13：装 Node.js 22 + OpenClaw 官方脚本
飞书：企业自建应用 + 机器人 + 长连接事件
本地即可跑，不用公网、不用 ngrok
接入后即可在飞书私聊 / 群聊（@机器人）使用本地 AI
